Welcome to the tutorial pages!

Here we will give a recap of our quick start guide, showing how to build and run a PRISMS-PF application and make basic changes to suit your needs. After reviewing this page, see the next page on the structure of a PRISMS-PF application. For developers, please check out our developer's guide to learn how to build this documentation locally and contribute to PRISMS-PF.

Getting Started

Before starting, you will need to install PRISMS-PF and its dependencies. For more information, see our Installation page.

Browse our example Applications and select one that solves a problem similar to your problem of interest. For this tutorial, we will use the explicit Allen-Cahn application.

Each application includes a minimum of three components. The first is a subclass of PDEOperatorBase, which contains the equations, initial conditions, and boundary conditions (called CustomPDE in the Allen-Cahn app, in custom_pde.h). The second part is a main.cc file containing the main function, which sets up the user inputs, instantiates CustomPDE, creates the Problem, and invokes Problem.solve(). The final part is a parameters file, typically called parameters.prm, which allows specifying different conditions under which to run the simulation. Our example applications also come with a markdown file containing a description of the equations being solved and the derivation of the weak form.

To run an application, you must first compile the code ("build the application"). To do this, navigate to the application's directory in your terminal and invoke cmake:

cmake . -DCMAKE_BUILD_TYPE=Debug
make

After compiling the application, you can run in serial (one processor) by simply invoking the main executable and specifying the parameters file using the -i option flag:

./main -i parameters.prm

To run with multiple processors using MPI, use mpirun:

mpirun -n 16 ./main -i parameters.prm

By default, the output files are saved in a directory called solutions in the same directory as the executable. You can change this and many other settings by editing the parameters file. See the Parameters page for more information on the available settings. For example, you can change the size of the finite element mesh and the simulation time step in the parameters file.

To implement your own app, you can start by copying the folder of an application solving a problem similar to yours (or copy the blank application). Then, edit the main.cc file to set up fields, solve blocks (a.k.a. solvers), and equations. For more information about the structure of an application, see Structure of aPRISMS-PF application".
